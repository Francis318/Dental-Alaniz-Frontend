# Clínica Dental Alaniz - Frontend 🦷

Proyecto frontend desarrollado en React (Vite) para la gestión y presentación de servicios de una clínica dental. Esta aplicación ofrece una interfaz intuitiva, un sistema de enrutamiento dinámico para perfiles de especialistas y está arquitectónicamente preparada para integrarse con una API REST en Node.js.

## 🚀 Características Principales

- **Arquitectura de Componentes:** Estructura modular y escalable usando React.
- **Rutas Dinámicas:** Implementación de `react-router-dom` para generar perfiles individuales de doctores desde una simulación de base de datos.
- **Diseño Responsivo:** Interfaz adaptable a múltiples dispositivos utilizando CSS Flexbox y Grid.
- **Metodología BEM:** Clases CSS estructuradas con el estándar _Block Element Modifier_ para un código limpio y mantenible.

## 🛠️ Tecnologías Utilizadas

- **React** (Hooks: `useState`, `useParams`)
- **Vite** (Entorno de desarrollo ultra rápido)
- **React Router DOM** (Navegación del lado del cliente)
- **CSS3** (Variables, Flexbox, BEM)
